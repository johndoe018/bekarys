1 Core Mathematics Topic & Differentiation Strategy

This web application dynamically differentiates mathematics learning across three core topics: Quadratic Equations, Systems of Linear Equations, and Calculus Derivatives.

  • Level 1 (Foundation): Uses integer coefficients, detailed step-by-step scaffolding, visual breakdown hints, and explicit guidance to build basic procedural understanding.
  • Level 2 (Standard): Uses grade-standard curriculum complexity (fractional roots, standard algebra) requiring standard problem-solving techniques without extra scaffolding.
  • Level 3 (Advanced): Introduces real-world applications (physics trajectories, economic optimization, projectile motion) requiring multi-step logic modeling.

2 System Prompts & AI Architecture

The application communicates directly with the Google Gemini API (`gemini-3-flash-preview`) using structured system prompts designed for educational scaffolding:

// System Instruction Sample
"You are an expert Math Pedagogy AI. Your task is to generate differentiated math problems based on target level: [Level 1/2/3].
Level 1 requires simplified steps and explicit guidance.
Level 2 requires standard curriculum level problems.
Level 3 requires real-world applied math challenges with multi-step reasoning.
Return response in strictly formatted JSON: { title, equation, context, answer, hints }."

3 UI/UX & Pedagogical Impact

The web app uses KaTeX for real-time mathematical expression rendering, Tailwind CSS for clean layout, and immediate AI feedback. Students receive instant level-adjusted support, avoiding cognitive overload while maintaining engagement through positive reinforcement.
